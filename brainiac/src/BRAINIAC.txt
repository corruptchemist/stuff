// BRAINIAC 0.5 -- a math solver for the TI-84 Plus CE (TI-BASIC source).

// Build it into BRAINIAC.8xp with:  python -m brainiac.build
// Needs calculator OS 5.2 or newer (for toString().
//
// Source conventions (see build.py): // notes, @labels, #sub/#call/#return,
// and \xNN for a token by its number (used inside quotes, where the build
// would otherwise spell sin( as the letters s,i,n).
// The build refuses any Goto, Menu( or #call inside a block, so a #call
// only ever appears at the top level of the code.
//
// The calculator has no empty strings: ""→Str1 is ERR:INVALID DIM. So any
// string built up piece by piece starts as "?" (a character the program
// never shows), and the ? is taken off at the end with sub(. A string that
// is still just "?" is the "nothing" case.
//
// The big idea: most of algebra class is polynomials, and a polynomial is
// pinned down by its values. Brainiac works an expression out at a handful
// of points on a circle in the complex plane and turns those values back
// into exact coefficients (a discrete Fourier transform). Knowing that
// X²+5X+20 really is 1, 5, 20 lets it solve, factor, simplify and
// rearrange exactly. Anything that isn't a polynomial (sin, √, ln, ...)
// falls back to a numeric search for zeros.
//
// Variables that keep their meaning across subroutines:
//   M  which mode we're in      G  how many letters the input uses
//   R  next screen row          θ  return address (used by #return)
//   Z  1 if the last step worked
// Every other letter is scratch: each #sub lists the ones it changes.
//
// Lists: BS call stack; BV1..BV6 values for the letters (by place in Str7);
// P* the polynomial being worked on (PC value, PP/PQ as a fraction, PE power
// of π, PK letter powers as digits); F* factoring; Z* the zero search.
// Strings: Str1 what was typed, Str2 working expression, Str7 the letters,
// Str9 the expression ready for expr(, Str0 output text. Others are scratch.
